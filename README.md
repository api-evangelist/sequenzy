Sequenzy provides an AI‑native email marketing platform for SaaS companies, enabling automated onboarding sequences, trial emails, and transactional messages triggered by events such as Stripe payments. The service offers a REST API, CLI, and AI agent integration, allowing developers to create, manage, and send targeted email campaigns without per‑contact pricing. Features include event‑driven automation, revenue attribution, and a dashboard for monitoring email performance.

**Areas:** EmailMarketing · AI · SaaS · Automation · API · DeveloperTools

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Sequenzy: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
